# Roadmap

## Version 0.1 — Current

- Streamlit interface with three tabs: Simulator, Distances, Parameters
- CSV-based parameters (vehicles, cargo types, modals, additional costs)
- Freight calculator with full calculation memory
- IBGE municipality extraction script
- Input validation
- README with methodology description

## Version 0.2

- IBGE API extraction integrated into app startup
- SQLite database to store simulation history
- Export calculation memory to CSV
- Notebook for exploratory distance analysis

## Version 0.3

- Dashboard with freight analysis by origin UF
- Modal comparison view
- FastAPI layer exposing the calculator as an endpoint
- Deploy on Streamlit Community Cloud
